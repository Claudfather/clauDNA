# Intent Interview Questions

Ask the user a focused set of questions about the **purpose** of the system. These are not code questions — they're product questions.

Ask these one group at a time, waiting for answers:

## Group A: Core Purpose

- What problem does this system solve?
- Who uses it? (end users, internal team, other systems?)
- What does success look like for this system?

## Group B: Current State

- What's working well today?
- What frustrates you or your users most?
- Are there things the system *should* do but doesn't?

## Group C: Aspirations

- If you could snap your fingers and improve one thing, what would it be?
- Are there capabilities you've thought about but haven't built?
- What would make this system a "10 out of 10"?

Capture the answers as structured notes — you'll reference these in the gap analysis.
